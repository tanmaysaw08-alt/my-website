MY WEBSITE - START HERE

1. Open this exact folder in VS Code.

2. Open VS Code Terminal.

3. Install Flask:
pip install -r requirements.txt

4. Start website:
python app.py

5. Open:
http://127.0.0.1:5000

6. Admin:
http://127.0.0.1:5000/admin

Admin password:
1234

7. Form submissions are saved automatically in:
submissions.db

IMPORTANT:
This is a clean new project. Do not mix it with your old full_stack_website project.
For a real public website, deploy this project to a hosting service and change the admin password.
